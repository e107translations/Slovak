**[e107][1]** je bezplatný systém na správu obsahu (CMS) s otvoreným zdrojovým kódom, ktorý vám umožní jednoducho spravovať a publikovať obsah online. Vývojári ušetria čas pri tvorbe webových stránok a výkonných online aplikácií. Užívatelia sa programovaniu môžu úplne vyhnúť! Blogy, webové stránky, intranety – e107 zvládne všetko.

## Požiadavky

   ### Minimálne

   * Webový server (Apache alebo Microsoft IIS) s PHP 7.4 alebo novším
   * MySQL 4.x alebo novšie, alebo MariaDB
   * FTP prístup na váš webový server a FTP klient (napríklad FileZilla)
   * Užívateľské meno a heslo k vašej MySQL databáze

   ### Odporúčané

   * Apache 2.4 alebo novší na Linuxe
   * PHP 7.4 alebo novšie
   * MySQL 5.6 alebo novšie, alebo MariaDB 10.3 alebo novšie
   * Registrovaná doména
   * Prístup k ovládaciemu panelu servera (napríklad cPanel)

**Verzie** používajú [pesimistický operátor z Ruby](https://guides.rubygems.org/patterns/#pessimistic-version-constraint): `~> 2.3.0` zodpovedá `>= 2.3.0, < 2.4.0`.
- **Vydanie** je dátum, kedy bolo zverejnené prvé vydanie danej rady.
- **Koniec nových funkcií** je dátum, po ktorom sa do danej rady nepridávajú žiadne nové funkcie.
- **Koniec údržby** je dátum, po ktorom sa v danej rade už neopravujú chyby ani bezpečnostné problémy.
- **Koniec obnovy** je dátum, po ktorom je daná rada úplne opustená a s jej obnovením sa už nepočíta.

### Kompatibilita s PHP

| Verzia softvéru     | Minimálna verzia PHP | Maximálna verzia PHP          | Príčina zmeny kompatibility |
|---------------------|----------------------|-------------------------------|-----------------------------|
| `~> 0.7`            | 4.3                  | _Neznáma_                     | Prvá explicitná spodná hranica v `install.php` (`$required_php = '4.3'`). |
| `~> 1.0.0`          | 4.3                  | _Neznáma_                     | Rovnaká hranica pri inštalácii; medzi verziami 0.7 a 1.0 nie je zdokumentovaná žiadna práca na verziách PHP. |
| `>= 2.0.0, < 2.3.0` | 5.3                  | _Neznáma_                     | `install.php` prešiel na konštantu `MIN_PHP_VERSION` nastavenú na `5.3`. |
| `>= 2.3.0, < 2.3.4` | 5.6                  | 8.1.*                         | `MIN_PHP_VERSION` zvýšená na `5.6`; zavedený `composer.json` s platformou `5.6` a `require.php` `>= 5.6`. PHP 8.2+ zobrazuje upozornenia na zastarané funkcie (deprecations). |
| `~> 2.3.4`          | 5.6                  | _Žiadna známa nekompatibilita_ | Pribalené opravy upozornenia „`Cannot use bool as array`“, ktoré PHP 8.5 povýšilo, a normalizácia pre libxml ≥ 2.13 v `cleanHtml`. PHP 8.5 stále zobrazuje zostávajúce upozornenia na `setAccessible()` a ďalšie zastarané funkcie. |
| `~> 2.4.0`          | _Bude určená_        | _Žiadna známa nekompatibilita_ |                             |

**Verzia softvéru** používa obmedzenia verzií v štýle Ruby. Obmedzenie opisuje uzavretý rozsah verzií e107, pre ktorý platia nasledujúce dva stĺpce. Maximum môže byť _Žiadna známa nekompatibilita_, ak v čase vydania nebola dosiahnutá žiadna horná hranica; neskoršie vydania PHP môžu priniesť upozornenia na zastarané funkcie, ktoré tu nie sú zachytené.

## Inštalácia

### Štandardná inštalácia

1. [Stiahnite si e107](https://e107.org/download).
2. Rozbaľte stiahnutý súbor do požadovaného koreňového adresára webu.
   Často je to adresár s názvom `public_html`.
3. V prehliadači otvorte skript `install.php` (napr. `https://example.com/podadresar/install.php`)
4. Postupujte podľa sprievodcu inštaláciou vo vašom prehliadači.



### Inštalácia cez Git (vývojárska verzia)

1. Spustite nasledujúce príkazy, pričom '~' nahraďte koreňovým adresárom vášho webu (nadradeným adresárom `public_html`) a xxx:xxx požadovaným vlastníkom súborov e107.
   ```
   cd ~
   git clone https://github.com/e107inc/e107.git public_html
   chown -R xxx:xxx public_html
   ```
2. V prehliadači otvorte skript `install.php` (napr. `https://example.com/podadresar/install.php`)
3. Postupujte podľa sprievodcu inštaláciou vo vašom prehliadači.



## Hlásenie chýb

Pred nahlásením problému sa uistite, že používate najnovšiu verziu e107.
Chyby a návrhy na nové funkcie môžete nahlásiť na [stránke GitHub Issues projektu e107](https://github.com/e107inc/e107/issues).



## Prispievanie do vývoja

* Pre každý GitHub issue, na ktorom pracujete, pošlite 1 pull request.
* Uistite sa, že pri porovnaní súborov (diff) sa zobrazia iba riadky, ktoré ste skutočne zmenili.
  Niektoré textové editory menia každý riadok; tomu sa treba vyhnúť.
* Odporúčame nastaviť `git pull` tak, aby predvolene robil rebase na vetvu master, a vyhnúť sa tak zbytočným merge commitom. Nastavíte to vo svojej kópii repozitára v súbore `.git/config` takto:
  ```
  [branch "master"]
    rebase = true
  ```
* Návod, ako začať, nájdete v dokumente [CONTRIBUTING](https://github.com/e107inc/e107/blob/master/.github/CONTRIBUTING.md).
